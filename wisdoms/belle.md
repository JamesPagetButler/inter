## Mission 01 — inter#243 cost/capacity discovery (rounds 1 & 2, 2026-10-29)

### Source authentication
- **Content-farm tell:** multiple "different" sites repeating near-identical phrasing/figures for a "2026 [credits/hackathon]" topic (SEO listicles, `.pages.dev`, aggregators) = syndicated content-farming → SUSPECT until confirmed on the sponsoring org's OWN domain. First-party domain is the authentication signal.
- **Cross-source agreement ≠ truth.** N aggregators converging on one figure can be one stale press release syndicated N times (see Google Dev Program below).

### Confrontation (the E-axis)
- **A first-party fetch can REFUTE a prior napkin claim, not just confirm it.** Round-1 search said Google Developer Program = $299/yr + $500 credit (2024 press); the live first-party page showed $19.99/mo + $10/mo credit. Report what CHANGED; flag the discrepancy with possible explanations — never silently "resolve" a conflict.
- **Grade by evidence, honestly:** search-snippet = napkin/unconfronted; a fetched + read first-party page = confronted. Never label anything "validated." A verdict grades SOURCE AUTHENTICITY, not truth.

### Finding (the master-finder inheritance)
- **When the obvious first-party source is dead (404), find the real one.** ASUS's live product page 404s → the official ASUS manual via archive.org was authoritative. THEN check the archived copy for authenticity/tampering (title page, copyright boilerplate, injected content) before trusting it.

### The internal/external fact boundary (containment)
- **Facts the federation/beekeeper already knows are NOT external research questions** — legal/registration status, repo names, repo star-counts. Never place them in an external query (reverse-exfiltration). Flag "beekeeper-known / check internally" and move on.

### Framing (verify the question, not just the answer)
- **Confirm the requester/entity framing before researching.** Round-1 assumed a nonprofit (from CLAUDE.md context); it is the beekeeper's PERSONAL, OSS-leaning work. Wrong framing mis-aimed the whole pass. Verify WHO/WHAT the question is for, then research.

### Domain facts observed at Mission 01 (dated 2026-10-29; re-confront if anything contradicts them; these are claims, not settled facts, per rules 5 and 6)
- Crawl box (ASUS Crosshair V Formula-Z) is a HARD platform ceiling: **32GB DDR3 max, PCIe 2.0 only** (first-party ASUS manual E7477). RAM bottleneck is a platform ceiling, not budget — only a platform swap moves it.
- **Claude for Open Source** = confirmed personal/OSS capacity lever: 6mo free Max 20x, individual natural persons only, numeric OR discretionary "ecosystem-depends-on-it" eligibility (anthropic.com/claude-for-oss-terms; apply claude.com/open-source-max).
