# Restatement of Selected Material

## Abstract and Introduction (summary of mathematical content)

We describe a category, the objects of which may be viewed as models for homotopy theories. We show that for such models, "functors between two homotopy theories form a homotopy theory", or more precisely that the category of such models has a well-behaved internal hom-object.

The introduction states the following main results:

- **(0)** A complete Segal space has invariants such as a "homotopy category" and "function complexes", together with additional "higher composition" structure (§5).
- **(1)** There exists a simplicial closed model category in which the fibrant objects are precisely the complete Segal spaces (7.2).
- **(2)** This category is cartesian closed, and the cartesian closure is compatible with the model category structure. In particular, if $X$ is any object and $W$ is a complete Segal space, then the internal hom-object $W^{X}$ is also a complete Segal space (7.3).

The introduction also states the following relations:

- Any category $C$ gives rise to a complete Segal space by a classifying diagram construction.
- The classifying diagram of a category $C$ is $[n]\mapsto B\,\iso(C^{[n]})$, and $C$ is determined up to equivalence by this diagram (3.7).
- For a simplicial closed model category $\mathbf{M}$, the classification diagram $[n]\mapsto \class(\mathbf{M}^{[n]})$ is essentially a complete Segal space (8.3).
- A consequence (8.12) of a result of Dwyer and Kan gives a natural weak equivalence $N(\mathbf{M}^{I})\to N^{f}(\mathbf{M})^{N(I)}$ when $\mathbf{M}=\mathcal{S}^{J}$ and $I$, $J$ are small categories.

## Labelled Statements

**Proposition 3.2.** The nerve of $[n]$ is $\Delta[n]$. For categories $C$ and $D$ there are natural isomorphisms
$$\nerve(C\times D)\approx\nerve C\times\nerve D \qquad\text{and}\qquad \nerve(D^{C})\approx\nerve(D)^{\nerve(C)}.$$
The functor $\nerve\colon \mathcal{C}at\to\mathcal{S}$ is a full embedding of categories. Furthermore, if $C$ is a groupoid then $\nerve(C)$ is a Kan complex.

**Theorem 3.7.** Let $C$ and $D$ be categories. There are natural isomorphisms
$$N(C\times D)\approx NC\times ND \qquad\text{and}\qquad N(D^{C})\approx(ND)^{NC}$$
of simplicial spaces. The functor $N\colon \mathcal{C}at\to s\mathcal{S}$ is a full embedding of categories. Furthermore, a functor $f\colon C\to D$ is an equivalence of categories if and only if $Nf$ is a weak equivalence of simplicial spaces.

**Lemma 3.8.** Let $C$ be a category. Then there are natural isomorphisms
$$N([m]\times C)\approx F(m)\times NC \qquad\text{and}\qquad N(C^{I[n]})\approx(NC)^{\Delta[n]}$$
of simplicial spaces.

**Lemma 3.9.** If $C$ is a category, then $NC$ is a Reedy fibrant simplicial space.

**Proposition 3.11.** Let $C$ and $D$ be categories, and $W\subset D$ a subcategory such that $\iso D\subset W$. Then there are natural isomorphisms
$$N(D^{C},\we(D^{C}))\approx N(D,W)^{NC}\approx N(D,W)^{\discnerve C}.$$

**Lemma 3.12.** Let $C$ be a category, and $W$ a subcategory with $\ob W=\ob C$. Then there is a natural isomorphism
$$N(\widetilde{C^{[n]}},\we(\widetilde{C^{[n]}}))\approx (NC)^{\Delta[n]},$$
where $\widetilde{C^{[n]}}\subset C^{[n]}$ denotes the full subcategory whose objects are those functors $[n]\to C$ which factor through $W\subset C$, and $\we(\widetilde{C^{[n]}})=\we(C^{[n]})\cap\widetilde{C^{[n]}}$.

**Remark 5.2.** If $C$ is a category and either $W=\discnerve C$ or $W=NC$, then $\ob W\approx\ob C$ and $\map_{W}(x,y)\approx\hom_{C}(x,y)$.

**Proposition 5.4.** Given points $f\in\map(w,x)$, $g\in\map(x,y)$, and $h\in\map(y,x)$, we have $(h\circ g)\circ f\sim h\circ(g\circ f)$ and $f\circ\id_{w}\sim f\sim\id_{x}\circ f$.

**Remark 5.6.** By (3.5) there is an embedding $N\colon\mathcal{C}at\to s\mathcal{S}$ via the classifying diagram construction, which by (4.4) lands in the subcategory of Segal spaces. By (5.2), $\ho NC\approx C$. The functor $N$ admits a left adjoint $L\colon s\mathcal{S}\to\mathcal{C}at$, and $L(W)\approx\ho W$ whenever $W$ is a Segal space. (Stated as possible to show.)

**Lemma 5.8.** If $g\in W_1$ is a vertex which can be connected by a path in $W_1$ to a homotopy equivalence $g'\in W_1$, then $g$ is itself a homotopy equivalence.

**Proposition 6.1.** If $C$ is a small category, then the classifying diagram $NC$ of (3.5) is a complete Segal space.

**Theorem 6.2.** If $W$ is a Segal space, then $\Map_{s\mathcal{S}}(E,W)\to W_1$ factors through $W_{\hoequiv}\subseteq W_1$, and induces a weak equivalence $\Map_{s\mathcal{S}}(E,W)\to W_{\hoequiv}$.

**Proposition 6.4.** Let $W$ be a Segal space. The following are equivalent.
1. $W$ is a complete Segal space.
2. The map $W_0\to\Map_{s\mathcal{S}}(E,W)$ induced by $E\to F(0)$ is a weak equivalence.
3. Either of the maps $\Map_{s\mathcal{S}}(E,W)\to W_0$ induced by a map $F(0)\to E$ is a weak equivalence.
4. For each pair $x,y\in\ob W$, the space $\hoequiv(x,y)$ is naturally weakly equivalent to the space of paths in $W_0$ from $x$ to $y$.

**Corollary 6.5.** Let $\ob W/{\sim}$ denote the set of homotopy equivalence classes of objects in $\ho W$. If $W$ is a complete Segal space, then $\pi_0 W_0\approx\ob W/{\sim}$.

**Corollary 6.6.** Let $W$ be a complete Segal space. Then $\ho W$ is a groupoid if and only if $W$ is Reedy weakly equivalent to a constant simplicial space.

**Theorem 7.1.** There exists a simplicial closed model category structure on the category $s\mathcal{S}$ of simplicial spaces, called the Segal space model category structure, with the following properties.
1. The cofibrations are precisely the monomorphisms.
2. The fibrant objects are precisely the Segal spaces.
3. The weak equivalences are precisely the maps $f$ such that $\Map_{s\mathcal{S}}(f,W)$ is a weak equivalence of spaces for every Segal space $W$.
4. A Reedy weak equivalence between any two objects is a weak equivalence in the Segal space model category structure, and if both objects are themselves Segal spaces then the converse holds.

Moreover, this model category structure is compatible with the cartesian closed structure on $s\mathcal{S}et$ in the sense of Section 2.

**Theorem 7.2.** There exists a simplicial closed model category structure on the category $s\mathcal{S}$ of simplicial spaces, called the complete Segal space model category structure, with the following properties.
1. The cofibrations are precisely the monomorphisms.
2. The fibrant objects are precisely the complete Segal spaces.
3. The weak equivalences are precisely the maps $f$ such that $\Map_{s\mathcal{S}}(f,W)$ is a weak equivalence of spaces for every complete Segal space $W$.
4. A Reedy weak equivalence between any two objects is a weak equivalence in the complete Segal space model category structure, and if both objects are themselves complete Segal spaces then the converse holds.

Moreover, this model category structure is compatible with the cartesian closed structure on $s\mathcal{S}et$ in the sense of Section 2.

**Corollary 7.3.** If $W$ is a complete Segal space (resp. a Segal space) and $X$ is any simplicial space, then $W^{X}$ is a complete Segal space (resp. a Segal space).

**Lemma 7.5.** Let $U\xrightarrow{f}V\xrightarrow{g}W$ be maps of Segal spaces such that $f$ and $g$ are Dwyer–Kan equivalences. Then $gf$ is a Dwyer–Kan equivalence. If $U\xrightarrow{f}V\xrightarrow{g}W\xrightarrow{h}X$ are maps of Segal spaces such that $gf$ and $hg$ are Dwyer–Kan equivalences, then each of $f$, $g$, and $h$ is a Dwyer–Kan equivalence.

**Proposition 7.6.** A map $f\colon U\to V$ of complete Segal spaces is a Dwyer–Kan equivalence if and only if it is a Reedy weak equivalence.

**Theorem 7.7.** Let $f\colon U\to V$ be a map between Segal spaces. Then $f$ is a Dwyer–Kan equivalence if and only if it becomes a weak equivalence in the complete Segal space model category structure.

**Remark 7.8.** If $C$ is a category, then the natural inclusion $\discnerve(C)\to N(C)$ of simplicial spaces is a Dwyer–Kan equivalence; thus by (7.7) this map is a weak equivalence in the complete Segal space model category structure.

**Corollary 7.9.** The homotopy category of complete Segal spaces may be obtained by formally inverting the Dwyer–Kan equivalences in the homotopy category of Segal spaces.

**Theorem 8.3.** Let $\mathbf{M}$ be a simplicial closed model category, and let $\mathbf{W}\subset\mathbf{M}$ denote the subcategory of weak equivalences. Then $V=N^{f}(\mathbf{M},\mathbf{W})$ is a complete Segal space. Furthermore, there is an equivalence of categories $\ho V\approx\ho\mathbf{M}$, and there are weak equivalences of spaces $\map_{V}(X,Y)\approx\map_{\mathbf{M}}(X,Y)$.

**Remark 8.4.** This result (8.3) presumably generalizes to an arbitrary closed model category, not necessarily simplicial; the function complex $\map_{V}(X,Y)$ would be taken to be one of those described by Dwyer and Kan in [DK80].

**Remark 8.5.** Any category $C$ having finite limits and colimits can be made into a closed model category in which the weak equivalences are precisely the isomorphisms (and all maps are fibrations and cofibrations). In this case $N(C)=N(C,\iso C)$ coincides with the classifying diagram construction described in (3.5), and this is already a complete Segal space by (6.1).

**Proposition 8.7 (Dwyer–Kan [DK84a, 2.3, 2.4]).** Given a simplicial closed model category $\mathbf{M}$ and an object $X\in\mathbf{M}$ which is both fibrant and cofibrant, let $\haut X\subset\map_{\mathbf{M}}(X,X)$ be its simplicial monoid of weak equivalences. Then the classifying complex $\bar{W}\haut X$ is weakly equivalent to $\sclass X$. In fact, $\bar{W}\haut X$ and $\sclass X$ can be connected by a finite string of weak equivalences which is natural with respect to simplicial functors $f\colon\mathbf{M}\to\mathbf{N}$ between closed model categories which preserve weak equivalences and are such that $fX\in\mathbf{N}$ is both fibrant and cofibrant.

**Remark 8.8.** For any two fibrant-and-cofibrant objects $X,Y\in\mathbf{M}$, the space of paths from $X$ to $Y$ in $\class(\mathbf{M})$ is naturally weakly equivalent to the space $\hoequiv_{\mathbf{M}}(X,Y)\subset\map_{\mathbf{M}}(X,Y)$ of homotopy equivalences from $X$ to $Y$. (Compare with (6.4, 4).)

**Theorem 8.11.** The map $f$ of (8.10) is a Reedy weak equivalence when $\mathbf{M}=\mathcal{S}^{\mathbf{J}}$, where $\mathcal{S}$ denotes the category of simplicial sets and $\mathbf{J}$ is a small indexing category.

**Corollary 8.12.** There is a natural weak equivalence $N(\mathbf{M}^{I})\xrightarrow{\sim}N^{f}(\mathbf{M})^{N(I)}$ of complete Segal spaces if $\mathbf{M}=\mathcal{S}^{J}$ and $I$ and $J$ are small categories.

**Remark 8.13.** The theorem of Dwyer and Kan, and hence the statements of (8.11) and (8.12), should hold for any "reasonable" model category $\mathbf{M}$, where the class of "reasonable" closed model categories includes at least the "cofibrantly generated" simplicial closed model categories. Future work may generalize these theorems to arbitrary closed model categories.

**Theorem 8.14 (Dwyer–Kan).** Let $I$ be a small category. The natural map
$$\class(\mathcal{S}^{I})\approx\lim_{([k]\to I)\in\boldsymbol{\Delta}^{\operatorname{op}}I}\class(\mathcal{S}^{[k]})\to\holim_{([k]\to I)\in\boldsymbol{\Delta}^{\operatorname{op}}I}\class(\mathcal{S}^{[k]})^{f}$$
is a weak equivalence, where $X^{f}$ denotes the fibrant replacement of a space $X$, and $\holim$ is the homotopy inverse limit construction of [BK72].

**Lemma 8.15.** Let $I$ be a small category and let $W$ be a Reedy fibrant simplicial space. Then the natural map
$$\Map_{s\mathcal{S}}(\discnerve I,W)\approx\lim_{([k]\to I)\in\boldsymbol{\Delta}^{\operatorname{op}}I}W_k\to\holim_{([k]\to I)\in\boldsymbol{\Delta}^{\operatorname{op}}I}W_k$$
is a weak equivalence.

**Proposition 9.1.** Given an inclusion $f\colon A\to B\in s\mathcal{S}$, there exists a cofibrantly generated simplicial model category structure on $s\mathcal{S}$ with the following properties.
1. The cofibrations are exactly the inclusions.
2. The fibrant objects (called $f$-local objects) are exactly the Reedy fibrant $W\in s\mathcal{S}$ such that $\Map_{s\mathcal{S}}(B,W)\to\Map_{s\mathcal{S}}(A,W)$ is a weak equivalence of spaces.
3. The weak equivalences (called $f$-local weak equivalences) are exactly the maps $g\colon X\to Y$ such that for every $f$-local object $W$, the induced map $\Map_{s\mathcal{S}}(Y,W)\to\Map_{s\mathcal{S}}(X,W)$ is a weak equivalence.
4. A Reedy weak equivalence between two objects is an $f$-local weak equivalence, and if both objects are $f$-local then the converse holds.

**Proposition 9.2.** Suppose that for each $f$-local object $W$, the simplicial space $W^{F(1)}$ is also $f$-local. Then the $f$-local model category structure on $s\mathcal{S}$ is compatible with the cartesian closure.

**Lemma 10.1.** Let $G\subset F(n)$ be a cover. Then the inclusion maps $G(n)\xrightarrow{i}G\xrightarrow{j}F(n)$ are weak equivalences in the Segal space model category structure.

**Remark 10.2.** The class of subobjects which are weakly equivalent to $F(n)$ is not exhausted by the coverings. For example, for $0<i<n$ the subobject $\dot{F}(n)\setminus d^{i}F(n-1)$ is weakly equivalent to $F(n)$ in the Segal space model category structure, but is not a cover.

**Lemma 10.3.** The inclusion $F(1)\times G(n)\to F(1)\times F(n)$ is a weak equivalence in the Segal space model category structure.

**Proposition 11.1.** If $W$ is a Segal space and $n\geq 3$, the map $\Map_{s\mathcal{S}}(E^{(n)},W)\to W_1$ factors through the subspace $W_{\hoequiv}\subseteq W_1$, and induces a weak equivalence $\Map_{s\mathcal{S}}(E^{(n)},W)\to W_{\hoequiv}$.

**Proposition 11.3.** (1) Given $f\in\map(x,y)$ and $g\in\map(y,z)$, with $g\circ f$ the result of a composition, then $(g\circ f)_*\sim g_*\circ f_*$ and $(g\circ f)^*\sim f^*\circ g^*$. (2) Given $x\in\ob W$, then $(\id_x)_*\sim(\id_x)^*\sim\id_{\map(x,x)}$.

**Proposition 11.4.** Let $f,g\in\map(x,y)$. Then $f\sim g$ if and only if the maps $f_*,g_*\colon\map(w,x)\to\map(w,y)$ are homotopic for all $w\in\ob W$, if and only if the maps $f^*,g^*\colon\map(y,z)\to\map(x,z)$ are homotopic for all $z\in\ob W$.

**Corollary 11.5.** If $f\in\map(x,y)$ is a homotopy equivalence (in the sense of (5.5)), then $f_*$ and $f^*$ are weak equivalences of spaces.

**Lemma 11.6.** Given a Segal space $W$, and $f\in\map(x,y)$ and $g\in\map(y,z)$ such that $f$ is a homotopy equivalence, the induced map $\map(x,y,z)_{f,g}\xrightarrow{(d_1,d_2)}\map(x,z)_{g\circ f}\times\map(x,y)_{f}$ is a weak equivalence.

**Lemma 11.10.** Let $W$ be a Segal space. Then for $k\geq 2$ the induced map $\Map_{s\mathcal{S}}(F(k),W)_{\hoequiv}\to\Map_{s\mathcal{S}}(H(k),W)_{\hoequiv}$ is a weak equivalence.

**Lemma 11.11.** There is a natural weak equivalence
$$\Map_{s\mathcal{S}}(C(k),W)\approx\Map(d^{1}H(k-1),W)\times_{W_0}W_1.$$

**Proposition 12.1.** If $W$ is a complete Segal space, then the map $g\colon (W^{F(1)})_0\to(W^{F(1)})_{\hoequiv}$ is a weak equivalence.

**Lemma 12.4.** Let $W$ be a Segal space. Then the squares built from the face and degeneracy maps $s_0, s_1, d_0, d_1, d_2$ on $W_0, W_1, W_2$ (as displayed in the source) are homotopy pullback squares.

**Proposition 13.2.** If $U$ is a Segal space and $W$ is a complete Segal space, then a pair of maps $f,g\colon U\rightrightarrows W$ are categorically homotopic if and only if they are homotopic in the usual sense; i.e., if there exists a map $K\colon U\times\Delta[1]\to W$ which restricts to $f$ and $g$ on the endpoints of $\Delta[1]$.

**Proposition 13.4.** A map $g\colon U\to V$ between complete Segal spaces is a categorical equivalence if and only if it is a simplicial homotopy equivalence, if and only if it is a Reedy weak equivalence.

**Proposition 13.5.** Let $A$, $B$, and $W$ be Segal spaces. If $f,g\colon A\rightrightarrows B$ are categorically homotopic maps, then the induced maps $W^{B}\rightrightarrows W^{A}$ are categorically homotopic. If $f\colon A\to B$ is a categorical equivalence, then the induced map $W^{B}\to W^{A}$ is a categorical equivalence.

**Proposition 13.6.** If $f\colon U\to V$ is a categorical equivalence between Segal spaces, then it is a weak equivalence in the complete Segal space model category structure.

**Proposition 13.8.** If $g\colon U\to V$ is a categorical equivalence of Segal spaces, then it is a Dwyer–Kan equivalence.

**Lemma 13.9.** If $W$ is a Segal space, the map $W\to W^{E}$ and both maps $W^{E}\to W$ are Dwyer–Kan equivalences.

**Remark 14.1.** This completion is a generalization of the classifying space construction. Suppose $W$ is a Segal space such that $\ho W$ is a groupoid; equivalently, $W_1=W_{\hoequiv}$. Then $\widehat{W}$ is weakly equivalent to a constant simplicial space, which in each degree is the realization $\diag W$. If $W$ is a "$\Delta$-space" (i.e., $W_0=*$) and thus a model for a loop space with underlying space equivalent to $W_1$, then $\widehat{W}$ is equivalent to the constant object $BW_1$ in each degree.

**Lemma 14.2.** If $C$ is a category, then $\widetilde{\discnerve C}$ is isomorphic to $NC$. In particular, $NE\approx\widetilde{E}$ and $\widehat{E}$ are weakly equivalent to the terminal object in $s\mathcal{S}$.

**Lemma 14.3.** If $U\to V$ is a categorical equivalence between Segal spaces, then $\widehat{U}\to\widehat{V}$ is a Reedy weak equivalence.
