# Restatement

## 1. Introduction

The spectrum of the Dirac operator has been explicitly computed for spherical space forms, flat manifolds, and spheres with Berger metrics [8, 7, 2, 3, 12].

Let $D = D_g$ denote the Dirac operator of a Riemannian metric $g$. It is a first-order elliptic operator acting on sections of the spinor bundle $\Sigma M = \operatorname{Spin}(M,g) \times_\rho \Sigma$, where $\operatorname{Spin}(M,g) \to SO(M,g)$ is a spin structure on $M$, and $\rho: \operatorname{Spin}(n) \to \operatorname{End}(\Sigma)$, with $\Sigma = \mathbb{C}^{2^{[n/2]}}$, is the spinor representation. The operator $D$ is formally self-adjoint, and on a compact manifold it has discrete real spectrum.

In dimensions $n \equiv 3, 4, 5 \mod 8$ the spinor representation is quaternionic. That is, there is an $\mathbb{R}$-linear endomorphism $J$ of $\Sigma$ with $J^2 = -1$ and $Ji = -iJ$, which commutes with the action of $\operatorname{Spin}(n)$. In dimension three the spinor bundle is a quaternionic line bundle, and the eigenspaces $E_\lambda$ of $D$ are quaternionic vector spaces. An eigenvalue $\lambda$ is simple if $\dim_{\mathbb{H}} E_\lambda = 1$.

For a compact spin manifold $M$, let $R(M)$ denote the space of Riemannian metrics on $M$, equipped with the $C^1$-topology. Let $S(M)$ denote the subset of metrics for which all eigenvalues of the Dirac operator are simple. A subset of a topological space is called *residual* if it contains a countable intersection of open and dense sets.

**Theorem 1.1.** For a generic metric on a compact spin three-manifold the Dirac operator has only simple eigenvalues.

**Theorem 1.2.** Let $M$ be a compact spin manifold of dimension three. Then $S(M)$ is residual.

**Remark 1.3.**
(1) In each conformal class, the set of metrics for which all non-zero eigenvalues are simple is residual.
(2) In any dimension, the set of metrics for which $\dim E_\lambda \leq \operatorname{rank} \Sigma M$ for all non-zero $\lambda$ is residual. Only in dimension three is $\operatorname{rank} \Sigma M = 1$.

## 2. Perturbation of eigenvalues

**Theorem 2.1.** Suppose $\lambda$ is an eigenvalue of $D$ with $\dim_{\mathbb{C}} E_\lambda = p$. Then there exist real analytic functions $\lambda_1^t, \dots, \lambda_p^t$ and curves of smooth spinor fields $\varphi_1^t, \ldots, \varphi_p^t$ (defined for small $t$) such that:
- $D^t \varphi_i^t = \lambda_i^t \varphi_i^t$, for $i = 1, \dots, p$;
- $\lambda_i^0 = \lambda$, for $i = 1, \dots, p$;
- $\varphi_1^t, \dots, \varphi_p^t$ are real analytic as maps $t \mapsto \varphi_i^t \in L^2(\Sigma M, g)$;
- $\varphi_1^t, \dots, \varphi_p^t$ are orthonormal in $L^2(\Sigma M, g^t)$.

**Remark 2.2.** If the spinor representation is quaternionic, $\dim_{\mathbb{C}}$ can be replaced by $\dim_{\mathbb{H}}$. In that case, "orthonormal" is interpreted as
$$(\varphi_i,\varphi_i)_g = 1, \quad (\varphi_i, J\varphi_i)_g = (\varphi_i,\varphi_j)_g = (\varphi_i, J\varphi_j)_g = 0, \quad i \neq j.$$
